# Study of Grokking

This project investigates the grokking phenomenon in small transformer models trained on modular arithmetic tasks.

## Main Topics
- Delayed generalization (grokking)
- Fourier analysis of learned representations
- Mechanistic interpretability
- Training dynamics
- Modular multiplication
